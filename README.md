## TODO 桌面待办事项工具

一个使用 **Python + CustomTkinter** 实现的现代扁平化风格 TODO 桌面工具，灵感来自滴答清单。

### 功能特性
- 左右分栏：左侧导航（今天 / 明天 / 本周 / 收件箱 / 已完成），右侧主操作区
- 顶部快速添加栏：任务标题 + 截止日期，支持回车快速添加
- 任务行：复选框完成、日期标签、删除二次确认
- 本地 `todos.json` 持久化，自动加载与实时保存，损坏文件会自动备份
- 内置暗色 / 亮色 / 跟随系统主题切换

### 安装

```bash
pip install -r requirements.txt
# 或：
pip install customtkinter
```

### 运行

```bash
python todo_app.py
```

数据保存在脚本同目录下的 `todos.json` 中。
